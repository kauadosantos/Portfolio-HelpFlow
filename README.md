# HelpFlow – Site Institucional

Site institucional da HelpFlow, empresa fictícia de suporte técnico e gestão de chamados para micro e pequenas empresas.

## Páginas
| Arquivo | Página | Conteúdo |
|---|---|---|
| `index.html` | Início | Logo, apresentação, "Como funciona", principais serviços e chamada para contato |
| `sobre.html` | Sobre | História, missão, visão, valores, área de atuação e diferenciais |
| `servicos.html` | Serviços | Catálogo de serviços em cards |
| `portfolio.html` | Portfólio | Projetos realizados e depoimentos de clientes (fictícios) |
| `contato.html` | Contato | Telefone, e-mail, endereço, horário e formulário (nome, e-mail e mensagem) |

## Estrutura
```
index.html, sobre.html, servicos.html, portfolio.html, contato.html
style.css   → estilo único, externo, usado por todas as páginas (responsivo)
script.js   → confirmação do formulário de contato (JavaScript, opcional)
img/logo.svg → logotipo
```

## Tecnologias
HTML5 e CSS3. JavaScript usado apenas na confirmação do formulário.
